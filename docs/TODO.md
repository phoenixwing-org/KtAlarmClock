## 本轮 UI 点检清单

实现与自动化检查：

- [x] 工作计时主数字按窗口高度垂直居中。
- [x] 锁屏主区（Phoenix Wing 标志、提示文字、时间）支持拖动。
- [x] 锁屏计算面板固定在左上角，不参与主区拖动。
- [x] 计算输入框保留数字输入、ASCII 数字过滤和回车提交。
- [x] 锁屏文字统一使用茶杯同色蓝色；错误提示保留红色以便识别。
- [x] 锁屏提供跨平台 `Esc` 保险解锁；强制休息期间不会绕过休息，显示器变化继续同步遮罩。
- [x] `cargo test -p kt-alarm-clock --tests`：6 个单元测试、1 个资源报告测试通过；资源采样测试按文档手工执行。

待用户手工确认：

- [ ] 工作计时窗口在不同屏幕边缘不会跑出可视区域，重启后恢复上次位置。
- [ ] 锁屏时主区拖动不会抢占计算输入框焦点，数字可正常输入和提交。
- [ ] 锁屏多屏遮罩均置顶，主区和左上角计算面板位置符合预期。
- [ ] 设置窗口内容自动适配且不可调整大小，右键菜单可打开设置和代码主页。
- [ ] macOS、Windows 分别检查输入法切换、窗口置顶、休息/解锁流程。
- [ ] 手工在“休息结束”后按 `Esc` 验证解锁并恢复工作；“休息进行”时按 `Esc` 应无效。
- [ ] 手工切换/拔插显示器，验证强制休息期间遮罩继续跟随且焦点不丢失。
- [ ] 休息结束后切换 macOS Space / Windows 虚拟桌面，验证等同解锁并恢复工作；强制休息期间切换不应退出。
