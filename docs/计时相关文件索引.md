# Rust 文件索引

## 应用与 UI

| 文件 | 职责 |
| --- | --- |
| `app/src/main.rs` | Backend 选择、事件循环、Slint 回调、Effect 执行、多屏窗口集合、测试模式 |
| `app/ui/app.slint` | 主胶囊、设置窗、休息遮罩、系统托盘；Windows/macOS 共用 |
| `app/build.rs` | 编译 `.slint` UI 与嵌入资源 |
| `app/tests/resource_usage.rs` | 启动独立 Release 子进程，采集两种模式的内存/CPU/体积 |

## Domain

| 文件/函数 | 职责 |
| --- | --- |
| `crates/clock-domain/src/model.rs` | `ClockModel`、`Phase`、`Snapshot`、`TimePoint` |
| `ClockModel::start_or_resume_work` | 开始或从手动暂停点继续工作 |
| `ClockModel::pause_work` | 同步剩余并进入 `Idle` |
| `ClockModel::start_break` | 建立休息与强制期绝对 deadline |
| `ClockModel::suspend` / `resume` | 工作冻结/恢复；休息只观察墙钟，不移动 deadline |
| `ClockModel::unlock_break` | 强制期结束后幂等离开休息并开始下一轮 |
| `crates/clock-domain/src/settings.rs` | 设置结构、schema version、范围校验与默认值 |

## Application Controller 与配置

| 文件 | 职责 |
| --- | --- |
| `crates/clock-app/src/controller.rs` | `Event` / `UserAction` → Model 调用 → `Effect` |
| `crates/clock-app/src/config.rs` | TOML 序列化、校验、临时文件/备份/替换 |

进入休息的关键 Effect 顺序位于 `Controller::dispatch` 和 `handle_user_action`：

```text
ShowBreakOverlays → HideMain
```

## 平台适配

| 文件 | Windows | macOS |
| --- | --- | --- |
| `crates/clock-platform/src/power.rs` | message-only HWND / `WM_POWERBROADCAST` | `NSWorkspace` sleep/wake 通知 |
| `autostart.rs` | HKCU Run；一次性读取旧计时注册表 | LaunchAgent plist |
| `instance.rs` | 文件锁 + loopback 随机端口激活 | 文件锁 + Unix socket 激活 |
| `monitor.rs` | `EnumDisplayMonitors` 原生兜底 | `NSScreen::screens()` 原生兜底 |
| `overlay.rs` | HWND topmost、`rcWork` 四边约束 | NSWindow level / Spaces behavior、`visibleFrame` 四边约束 |
| `resource.rs` | Working Set、PrivateUsage、CPU time | resident、physical footprint、CPU time |
| `lib.rs` | 配置目录和以上能力的统一公开入口 | 同左 |

平台代码不得包含业务状态或另一套 UI。原生 FFI 只放在对应 `cfg(target_os)` 模块，并为每个 unsafe 边界写明有效性依据。
