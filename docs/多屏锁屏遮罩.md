# 多屏休息遮罩

## 目标与边界

休息时，每块已连接显示器对应一个独立的 Slint `BreakWindow`。所有窗口显示同一套休息倒计时、强制状态和解锁交互；任意屏完成解锁都会一次性销毁整组遮罩。

这是健康提醒遮罩，不是操作系统安全锁；目标是在当前桌面尽量同时覆盖多块屏，并维持置顶。

## 首次进入时序

Controller 进入休息返回的 Effect 顺序固定为：

```text
ShowBreakOverlays → HideMain
```

runtime 在同一个事件循环回调中：

1. 枚举并排序全部显示器；
2. 为每块屏创建一个 `BreakWindow`；
3. 在 `show()` 前设置物理位置和尺寸；
4. 全部窗口进入集合后才隐藏主计时窗。

窗口首次 `show()` 后，Slint/winit 的本机窗口可能尚未同步建立，因此原生 topmost/Space 修正通过 `winit_window().await` 在下一次可用时执行。这不是旧实现的 10 秒副屏延迟；窗口集合已经在同一批次创建，异步步骤只补原生窗口属性。

## 显示器枚举

优先使用当前主窗口的 `winit::Window::available_monitors()`。如果它返回空集合，平台层提供原生兜底：

- macOS：`NSScreen::screens()`，将 AppKit point/左下原点转换为 winit 使用的物理像素/左上坐标；
- Windows：`EnumDisplayMonitors` + `GetMonitorInfoW`；
- 原生枚举仍失败：使用 `current_monitor()`；
- 连当前屏也不可得：创建一个 borderless fullscreen 默认屏窗口。

每块屏转成稳定比较键：

```text
(x, y, physical_width, physical_height, scale_factor_bits)
```

键只用于当前运行期比较，不写进配置文件。

## 原生窗口修正

Slint UI 始终是同一份，平台层只修改本机窗口属性：

| 平台 | 动作 |
| --- | --- |
| macOS | 从 raw AppKit `NSView` 取得 `NSWindow`；加入所有 Space、允许全屏辅助、Stationary，并提升到 screen-saver window level |
| Windows | 从 raw Win32 handle 取得 HWND，`SetWindowPos(HWND_TOPMOST)`，不改变已设置的屏幕矩形 |

窗口无边框、always-on-top，内容由 software renderer 绘制。

## 热插拔 reconcile

1 秒 timer 在休息期读取一次当前拓扑：

```text
expected = sorted(current monitor keys)
current  = sorted(existing overlay keys)
```

相等时不创建、不重绘窗口集合。不同则：

1. 先为新拓扑完整创建替代遮罩集合；
2. 原子替换 runtime 中的集合；
3. 逐个 `hide()` 旧窗口并让 Rust handle 离开作用域销毁。

“先新后旧”缩短新增屏幕未覆盖时间；显式 `hide()` 避免 macOS 上已删除窗口在事件循环结束前留下黑窗。主屏和副屏都不复用，退出休息后全部销毁，下次休息重新创建。

## 计时与窗口分离

所有遮罩读取同一个 Controller `Snapshot`，没有每屏独立 timer：

- `remaining_seconds` 同步；
- `forced` / `can_unlock` 同步；
- 算式答案由本次休息统一生成；
- 解锁事件幂等，重复回调不会重复开始工作。

休眠时休息 deadline 按墙钟继续；唤醒后窗口集合仍在，并在下一次平台事件/tick 刷新状态与显示器拓扑。

## 自动测试

纯拓扑算法覆盖：

- 枚举顺序变化不触发重建；
- 位置变化触发重建；
- DPI/scale 变化触发重建；
- 完全无法枚举时只使用一个默认全屏回退；
- 解锁与调试退出幂等。

Release 资源测试还会输出 `overlay_count` 与 `overlay_pixels`，用于区分不同屏幕布局下的 software framebuffer 成本。

## 真机验收矩阵

| 用例 | 预期 |
| --- | --- |
| 单屏进入/退出休息 20 次 | 每次只有一个遮罩；退出无黑窗 |
| 双屏、三屏进入休息 | 每屏各一个窗口，用户无明显副屏空窗期 |
| 休息中插入显示器 | 1 秒内出现新遮罩 |
| 休息中拔掉显示器 | 1 秒内移除旧窗口，剩余屏不叠窗 |
| 100% + 150%/200% 混合 DPI | 每块屏完整覆盖，无错位/越界 |
| 休息中睡眠再唤醒 | 墙钟状态正确，遮罩仍覆盖并置顶 |
| 其他 topmost/全屏程序抢前台 | 遮罩的目标层级行为符合平台限制 |

macOS 当前开发机已经完成单屏遮罩启动 smoke test。Windows 和真实双/三屏仍是发布前必须执行的实机验收，不能仅凭单元测试标记通过。
