# QWidget 分支点检表

适用分支：`qwidget`（Qt 5 + C++ + QWidget）。本表不用于 `qml` 或 `rust` 分支；两者应使用各自分支的构建和验收文档。

## 自动门禁

- [ ] `cmake --preset macos-debug` 配置成功
- [ ] `cmake --build --preset macos-debug` 编译成功
- [ ] `ctest --test-dir build/mac --output-on-failure` 通过（若当前构建目录未生成测试，记录为 N/A）
- [ ] `git diff --check` 无空白错误
- [ ] 源码中无 QML/JavaScript、Slint、Rust 或 WebView 运行时引用
- [ ] 许可证头与根目录 Apache-2.0 一致

## 基本功能

- [ ] 启动后显示计时胶囊，文字垂直居中，窗口置顶且不可调整大小
- [ ] 胶囊可拖动；移动到屏幕边缘后不会跑出工作区；位置重启后恢复
- [ ] 胶囊右键菜单可打开设置、立刻休息、在线帮助、代码主页和退出
- [ ] 托盘菜单与胶囊右键菜单均有“开源代码主页”，外部浏览器打开 `https://gitee.com/phoenixwing/KtAlarmClock`
- [ ] 托盘/锁屏中的图标为 Phoenix Wing 标志，休息界面茶杯仍正常显示

## 设置与计时

- [ ] 设置窗口黑底蓝色主题，内容决定固定大小，用户不能拉伸
- [ ] 工作、休息、强制休息输入支持旧 Qt 规则（`分:秒`、`Ns`、纯数字分钟）
- [ ] 10 秒步进按钮与输入框值一致；点击底部动作前先提交当前输入
- [ ] 工作暂停/继续、下一轮工作、立即休息均与显示值一致
- [ ] 休息进行中强制遮罩，不因普通 Esc 或右键操作退出
- [ ] 休息到点后可通过算式解锁；完成后恢复工作计时

## 多屏、休眠与平台

- [ ] 首次进入休息时所有当前显示器在同一事件批次创建遮罩，无明显逐屏闪烁
- [ ] 显示器热插拔、分辨率变化和 macOS 空间/Windows 虚拟桌面切换后，遮罩与计时同步
- [ ] 工作状态休眠/唤醒按墙钟校核；休息状态按进入休息时间点补算，不把休眠误判为暂停
- [ ] 双屏/三屏、混合 DPI 和高分辨率下遮罩覆盖完整且控件不出界
- [ ] Windows 实机或 CI 复核真实 MSVC 链接、启动、自启动和多屏；macOS 结果不能替代 Windows GUI 验收

## 记录

每次点检记录：日期、系统版本、Qt 编译器、显示器数量/DPI、通过项、失败项和复现步骤。未能在当天测试的 Windows 项保持未勾选，不用“已验证”表述。
