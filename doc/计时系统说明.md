# 计时系统说明

## 心智模型

项目里只有一个权威计时来源：C++ 的 QPC/monotonic countdown。QML 只展示状态和触发命令，不承担精准倒计时。

```text
KtAlarmClockController
  phase_ + loop_
  -> KtClockRuntime
     -> KtMonotonicCountdown
        -> KtQpcClock
```

## 阶段

| 阶段 | 枚举 | 含义 |
| --- | --- | --- |
| Idle | `KtAlarmClock::None` | 未运行或暂停 |
| Work | `KtAlarmClock::WorkTime` | 工作倒计时运行 |
| Break | `KtAlarmClock::WorkBreak` | 锁屏休息阶段 |

Controller 使用 `enter_phase(phase, resetDurationFromParam)` 进入阶段：

- `WorkTime`: 启动 `KtClockRuntime`。
- `WorkBreak`: 暂停工作 runtime，显示 `KtLockScreenManager`。
- `None`: 暂停 runtime，隐藏锁屏。

## Runtime

`KtClockRuntime` 是工作阶段的运行时包装：

- 持有 `KtMonotonicCountdown`。
- 用 `QTimer` 只做 UI 刷新节奏。
- 每次 tick 调 `sync_from_monotonic_clock()`。
- 到期后发出 `timeout(phase)`。

`KtMonotonicCountdown` 的核心公式：

```text
remaining = max(0, phaseDurationSec - (QPC_now_ms - phaseStartMs) / 1000)
```

所以即使系统睡眠、锁屏或事件循环延迟，恢复后也会按单调时间校准。

## 锁屏计时

锁屏阶段由 `KtLockScreenManager` 自己维护休息倒计时和强制期：

- `breakClock_`: 休息总倒计时。
- `forceEndMs_`: 强制期结束的 QPC 毫秒时间点。
- `isForced_`: 强制期内隐藏/禁止解锁。
- `counterForce_`: 强制期剩余秒数。

当休息倒计时结束后，Manager 允许 Resume/Unlock 退出，并发出 `clock_out(WorkBreak)`，Controller 再进入下一轮工作。

## 命令入口

QML 和托盘都只调用 Controller 命令：

- `playPause()`
- `startBreak()`
- `nextLoop()`
- `adjustRemaining(deltaSeconds)`
- `openSettings()`
- `saveSettings(...)`
- `resetSettings()`
- `quit()`

Controller 会在 `WorkBreak` 阶段通过 `is_forbidden()` 拦截普通用户动作。
