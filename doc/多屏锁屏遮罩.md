# 多屏锁屏遮罩

当前锁屏由 `KtLockScreenManager` 负责系统窗口和多屏编排，实际界面由 QML 组件渲染。

```text
KtLockScreenManager
  -> primary_      QQuickView + LockPrimary.qml
  -> secondaries_  QQuickView[] + LockSecondary.qml
```

## 职责边界

| 层 | 职责 |
| --- | --- |
| `KtLockScreenManager` | 枚举屏幕、创建/销毁 `QQuickView`、设置屏幕和几何、置顶、关闭拦截、QPC 休息/强制期同步 |
| `LockPrimary.qml` | 主屏倒计时、公式解锁、debug 退出和尺寸切换 |
| `LockSecondary.qml` | 副屏遮罩、休息提示、非强制期恢复入口 |
| `FormulaUnlock.qml` | 公式输入和提交 |

## 屏幕模型

- 主屏来自 `QGuiApplication::primaryScreen()`。
- 每次 `reconcile_screens()` 都重新读取 `QGuiApplication::screens()`，避免热插拔后使用过期下标。
- 生产模式下：主屏 1 个 primary，所有非主屏各 1 个 secondary。
- 单屏 debug 模式下：在主屏旁边模拟 1 个 secondary 小窗。

## 触发时机

| 触发 | 行为 |
| --- | --- |
| `show()` | 初始化休息倒计时和强制期，创建 primary，调用 `reconcile_screens()` |
| `screenAdded` / `screenRemoved` | 锁屏可见时立即 reconcile |
| `ApplicationActive` | 睡眠/锁屏恢复后同步 QPC 倒计时并重新置顶 |
| `watchdogTimer` | 每 10 秒兜底 reconcile |
| `hide()` | 停止计时，销毁 secondary，隐藏可复用的 primary |

## 解锁规则

- 强制期内 `unlockVisible=false`，所有用户动作被隐藏或忽略。
- 强制期结束后，主屏显示公式输入。
- 休息倒计时仍在运行时，答案必须等于随机加法题结果。
- 休息倒计时结束后，Resume/Unlock 可直接退出。
- 关闭事件由 `KtLockScreenManager::eventFilter` 拦截；未满足条件时忽略关闭。

## 单屏 Debug

`show(..., debugMode=true)` 用于开发：

- primary 默认为 1/4 屏。
- debug 按钮可切换半屏/全屏。
- secondary 以 640x480 小窗模拟。
- Controller 生产路径仍传入 `debugMode=false`，保证真实锁屏铺满目标屏幕。

## 验收重点

- 单屏可进入锁屏并通过公式/休息结束退出。
- 双屏时主屏显示 `LockPrimary.qml`，副屏显示 `LockSecondary.qml`。
- 拔出副屏后 secondary 立即隐藏并销毁。
- 插入副屏后新增 secondary。
- 睡眠/锁屏恢复后倒计时不漂移，窗口重新置顶。
- 100%、150%、175% DPI 下窗口几何和文字正常。
