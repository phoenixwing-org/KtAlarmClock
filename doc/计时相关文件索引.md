# 计时相关文件索引

> 当前实现是 C++ 业务核心 + QML UI。Qt Widgets 仍作为系统托盘依赖保留，但只隔离在 `KtTrayService` 和应用入口中。

## 核心状态与计时

| 文件 | 职责 |
| --- | --- |
| `KtAlarmClockUI/src/header/KtAlarmClock.h` | `WorkStep` / `ActionID` 等枚举，已通过 `Q_ENUM` 暴露给 Qt 元对象系统 |
| `KtAlarmClockUI/src/source/KtAlarmClockController.cpp` | 业务状态机：`enter_phase`、`run_command`、锁屏/托盘/QML 编排 |
| `KtAlarmClockUI/src/source/KtClockRuntime.cpp` | 工作阶段倒计时 runtime，内部使用 `KtMonotonicCountdown` |
| `KtAlarmClockUI/src/source/KtMonotonicCountdown.cpp` | 基于 QPC/monotonic clock 的倒计时核心 |
| `KtAlarmClockUI/src/source/KtQpcClock.cpp` | `QueryPerformanceCounter/Frequency` 封装 |

## 设置

| 文件 | 职责 |
| --- | --- |
| `KtAlarmClockUI/src/source/KtAlarmClockSettings.cpp` | 用户目录 ini 的读取、写入、归一化配置 |
| `KtAlarmClockUI/src/source/KtAlarmClockParam.cpp` | 参数对象与 `load/save` 入口 |
| `KtAlarmClockUI/res/qml/SettingsPanel.qml` | QML 设置面板 |
| `KtAlarmClockUI/res/qml/DurationField.qml` | 时长输入控件 |

## QML UI

| 文件 | 职责 |
| --- | --- |
| `KtAlarmClockUI/src/source/KtAlarmClockQmlShell.cpp` | 创建 `QQmlApplicationEngine`，暴露 `alarmModel` / `alarmController` |
| `KtAlarmClockUI/src/source/KtAlarmClockViewModel.cpp` | QML 状态出口：phase、running、remainingText、settingsVisible 等 |
| `KtAlarmClockUI/res/qml/Main.qml` | 主 QML 窗口 |
| `KtAlarmClockUI/res/qml/ClockBubble.qml` | 主浮窗胶囊 |
| `KtAlarmClockUI/res/qml/BubbleContextMenu.qml` | 主浮窗右键菜单 |

## 锁屏

| 文件 | 职责 |
| --- | --- |

| `KtAlarmClockUI/res/qml/PinCodeInput.qml` | 四位数字输入控件 |
