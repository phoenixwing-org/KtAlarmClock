# 计时相关文件索引

> 主流程与锁屏已迁移为 **C++ QWidget**；原 QML/JS 文件已移除。

## 核心 UI 与逻辑

| 文件 | 职责 |
| --- | --- |
| `KtAlarmClockUI/KtWallClockEngine.h/.cpp` | 墙钟引擎：`phaseStartMs_` / `phaseDurationSec_`、`start` / `pause` / `sync_from_wall_clock` |
| `KtAlarmClockUI/KtMainClockWidget.h/.cpp` | 主浮窗胶囊；内嵌 `KtWallClockEngine`；1s `QTimer` 刷新；拖动与右键菜单 |
| `KtAlarmClockUI/KtAlarmClockController.h/.cpp` | 主状态机：`run_command` / `clock_start` / `clock_timeout_impl`；`workStep_` / `loop_` |
| `KtAlarmClockUI/KtAlarmClockParam.h/.cpp` | 注册表读写 `WorkTime` / `WorkBreak` / `TimeForce` |
| `KtAlarmClockUI/KtAlarmClockCmd.cpp` | 启动入口：`build()` → `Controller::start()` → `ActionPlayPause` |

## 关键函数速查

### KtWallClockEngine

| 函数 | 作用 |
| --- | --- |
| `update_remaining_from_wall_clock()` | 按墙钟写 `counter_` |
| `sync_from_wall_clock()` | 每秒调用；到期则 `is_expired()` |
| `start(state, counterSec)` | 新阶段/继续：设起点并标记 running |
| `pause()` | 暂停：刷新剩余、清起点、停 running |
| `reset(state, counterSec)` | 重置阶段，停止计时 |

### KtAlarmClockController

| 函数 | 作用 |
| --- | --- |
| `clock_start(workStep)` | 切换 `workStep_`；WorkBreak 加载锁屏并暂停主钟 |
| `clock_timeout_impl(state)` | 阶段到点后的链式切换 |
| `run_command(ActionPlayPause)` | 暂停/继续/首次播放 |
| `sync_param_from_setting()` | 从设置窗 `update_infos()` 写回 `parameter` |
| `load_over_dlg()` | 显示锁屏并传入 `WorkBreak` / `TimeForce` |

### KtLockScreenManager

| 函数 | 作用 |
| --- | --- |
| `sync_wall_clocks()` | 校准休息钟 + 强制期 |
| `sync_force_from_wall_clock()` | 由 `forceEndMs_` 更新 `counterForce_` / `isForced_` |
| `show(breakSeconds, forceSeconds, debugMode)` | 进入锁屏时设定强制期起点并启动休息钟 |
| `reconcile_screens()` | 按屏数增删副屏遮罩；`screenAdded/Removed`、10s watchdog、唤醒时触发 |

### KtMainClockWidget

| 函数 | 作用 |
| --- | --- |
| `clock_start` / `clock_pause` | 委托 `workClock_` |
| `sync_from_wall_clock()` | 运行中 tick；到期 emit `clock_out` |
| `mouseMoveEvent` + `clamp_to_screen()` | 拖动主浮窗 |
