# 高分辨率 / 高 DPI 适配说明

> Windows 125%、150%、175%、200% 缩放及 4K 屏下的界面策略。  
> 相关：[多屏锁屏遮罩.md](./多屏锁屏遮罩.md)（跨屏 `setScreen`）

---

## 结论（先读）

| 层级 | 能否只靠 `.ui` | 说明 |
| --- | --- | --- |
| 应用级 DPI 声明 | 否 | 需 `main.cpp` 属性 + Windows `app.manifest` |
| 标准对话框（布局 + pt 字号） | **多数可以** | Designer 拉好布局即可 |
| 自绘浮窗、窄父窗口菜单、中英文混排列宽 | **不够** | 需少量 C++（`QFontMetrics`、`setScreen` 等） |

**不是每个控件都要写适配代码**，但也不要指望 `.ui` 单独搞定全部界面。

---

## Qt / Windows 自动做了什么

开启后，框架会按**逻辑像素**缩放大部分标准控件：

| 配置 | 位置 | 作用 |
| --- | --- | --- |
| `Qt::AA_EnableHighDpiScaling` | `KtAlarmClock/main.cpp` | Qt5 高 DPI 缩放 |
| `Qt::AA_UseHighDpiPixmaps` | `KtAlarmClock/main.cpp` | 图标按 DPI 选图 |
| `PassThrough` 舍入策略 | `KtAlarmClock/main.cpp` | 150%/175% 等非整数缩放更平滑 |
| PerMonitorV2 | `KtAlarmClock/app.manifest` + `main.rc` | 每块显示器独立 DPI |

这些**必须归档进 Git**（`app.manifest` 与 `main.rc` 绑定，缺了链接或 DPI 行为会不一致）。

## `.ui` / Designer 侧建议（优先做）

1. **全程用布局**（`QVBox` / `QHBox` / `QGrid`），避免固定 `geometry` 摆控件。
2. **字体用点（pt）**，不要在代码里对界面文字用 `setPixelSize`（像素不随 DPI 语义缩放，高分辨率下易偏小）。
3. **网格**：标签列设 `minimumSize`，滑条列设 `columnStretch = 1`。
4. **弹窗、菜单** 不要以极窄 `Tool` 窗口为父（例如 80px 胶囊浮窗），否则 `QMenu` 宽度可能被裁切。
5. **避免无意义的底部大 spacer**，会把中间行挤在一起。

做到以上，普通设置页、表单类界面通常**不必**再写一堆适配语句。

## 何时必须写 C++（本项目实例）

| 场景 | 原因 | 本项目做法 |
| --- | --- | --- |
| 主浮窗胶囊 `KtMainClockWidget` | 自绘圆角 + 按文字 `resize` | `setPointSize(12)`；高度随 `fontMetrics` |
| 设置窗 `KtAlarmClockSettingWindow` | 中英文标签列宽不足 → 叠字；行距过紧 | `apply_layout_metrics()` |
| 主浮窗右键菜单 | `QMenu(mainClock_)` 父窗口太窄 | `new QMenu()` 无父 + `min-width` |
| 多屏锁屏遮罩 | 每块屏 DPI 不同 | `windowHandle()->setScreen()` |
| 主浮窗拖动 | 跨屏 DPI 变化 | `setScreen()` + 四边 `clamp` |

## 本项目实现索引

### 应用入口

```
KtAlarmClock/main.cpp          — 高 DPI 属性、PassThrough
KtAlarmClock/app.manifest      — PerMonitorV2（须入库）
KtAlarmClock/main.rc           — RT_MANIFEST 嵌入 manifest
```

### 设置对话框

```
KtAlarmClockSettingWindow.ui   — 布局骨架（Designer 可改）
KtAlarmClockSettingWindow.cpp  — apply_layout_metrics()
```

`apply_layout_metrics()` 在 `setupUi` 之后执行，负责：

- 统一 **10pt** 正文字号（随 DPI 缩放）
- `QFontMetrics` 计算标签列 / 时间列 / spin 列最小宽度
- 网格横纵间距、外边距、行最小高度
- 图标按钮与「默认 / 保存」行高
- 对话框 `minimumSize` 与首次 `resize`

`set_param()` 内调用 `update_dialog()`，再次打开时从 **parameter** 恢复，不用 `.ui` 里的默认 slider 值。

### 主浮窗计时

```
KtMainClockWidget.cpp
```

- `TimeLabel`：`setPointSize(12)`，不用 `setPixelSize`
- 胶囊高度：`max(34, fontMetrics().height() + 10)`
- `apply_clamped_position()`：跨屏 `setScreen` + 四边限制

### 右键菜单

```
KtAlarmClockController.cpp — popMenu_ = new QMenu();
```

## 新增界面检查清单

```
- [ ] main.cpp / manifest 已配置（全应用一次即可）
- [ ] .ui 使用布局，无固定坐标摆满窗
- [ ] 字体在 .ui 或代码中用 pt，避免 pixel 字号
- [ ] 中英文混排标签列宽是否够用（Designer 或 QFontMetrics）
- [ ] QMenu / QDialog 父对象是否过窄
- [ ] 自绘 / 动态 resize 控件是否用 fontMetrics 算尺寸
- [ ] 多屏全屏窗是否 setScreen(targetScreen)
- [ ] 在 100% / 150% / 200% 缩放下目视验收
```

## 曾出现的问题与对策

| 现象 | 根因 | 对策 |
| --- | --- | --- |
| 设置窗标签叠字、挤成一团 | 网格列宽不足；9pt 过紧；底部 spacer | `apply_layout_metrics()`；加大间距 |
| 「默认」「保存」按钮字巨大 | 继承系统字号 + 行高被撑开 | 固定行高 + 统一 10pt |
| 主浮窗时间过小 | `setPixelSize(12)` | 改为 `setPointSize(12)` |
| 右键菜单文字被裁切 | 菜单父窗口为窄胶囊 | 独立 `QMenu()` + min-width |
| 跨屏后浮窗尺寸异常 | 未 `setScreen` | `apply_clamped_position` |

## 手动验收

1. Windows 显示设置：**100% / 150% / 200%** 各测一轮（可注销或重启应用）。
2. **设置窗**：三行标签完整、滑条可拖、底部按钮不压扁、不叠字。
3. **主浮窗**：时间清晰可读；右键菜单项完整显示。
4. **双屏不同缩放**：拖动主浮窗过屏，无 `setGeometry` 警告、尺寸正常。
5. **锁屏**：各屏遮罩铺满（见 [多屏锁屏遮罩.md](./多屏锁屏遮罩.md)）。
