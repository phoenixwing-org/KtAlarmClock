# 高分辨率适配

## 当前原则

项目当前 UI 是 QML，旧 `.ui` / QSS 适配说明已经不再适用。高 DPI 的重点变成：

- Windows manifest 声明 PerMonitorV2。
- 使用 Qt 6 默认 high DPI 行为。
- QML 中使用布局、固定控件尺寸和逻辑像素。
- 多屏窗口几何由 C++ 按 `QScreen::geometry()` / `availableGeometry()` 设置。

## Windows Manifest

入口工程通过 CMake 生成 rc：

```cmake
configure_file(.cmake/win_app.rc.in ${CMAKE_CURRENT_BINARY_DIR}/win_app.rc @ONLY)
```

manifest 位于：

```text
KtAlarmClock/.cmake/win_app.rc.in
```

这里以内联 manifest 继续负责 Windows DPI 感知声明。

## QML 侧约束

- 主浮窗和设置面板使用稳定宽高，避免状态变化导致布局跳动。
- 图标按钮使用固定 `implicitWidth/implicitHeight`。
- 锁屏 QML 使用布局和逻辑像素，不依赖硬编码物理像素。
- 不再使用 `.qss` 控制锁屏样式。

关键文件：

```text
KtAlarmClockUI/res/qml/Main.qml
KtAlarmClockUI/res/qml/ClockBubble.qml
KtAlarmClockUI/res/qml/SettingsPanel.qml
KtAlarmClockUI/res/qml/LockPrimary.qml
KtAlarmClockUI/res/qml/LockSecondary.qml
```

## C++ 多屏侧

锁屏窗口由 `KtLockScreenManager` 创建 `QQuickView`：

- primary 使用 `QGuiApplication::primaryScreen()`。
- secondary 按 `QGuiApplication::screens()` 创建。
- 生产模式使用 `showFullScreen()`。
- debug 模式使用小窗几何模拟多屏。

托盘菜单位置由 `KtScreenUtil::place_popup()` 约束在屏幕可用区域内。

## 验收项

- 100%、150%、175% 缩放下主浮窗文字不溢出。
- 设置面板字段和按钮不重叠。
- 锁屏主/副屏能铺满目标屏幕。
- 混合 DPI 多屏下，secondary 不跑到错误屏幕。
- 托盘菜单不会被屏幕边缘裁切。
